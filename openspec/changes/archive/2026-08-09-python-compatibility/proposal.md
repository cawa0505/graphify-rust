# Proposal: Python Compatibility for GraphifyRust Schema

## Intent
Ensure that the JSON output format (`graph.json`) generated by `GraphifyRust` is 100% backward-compatible with the Python `graphify` schema, allowing existing downstream tools, viewers, and Python scripts to ingest the Rust-generated graphs without modification.

## Scope
- Align `graphify-core::types::Node` to include `file_type` and other required fields.
- Align `graphify-core::types::Edge` to use `relation` instead of `kind`, and ensure `source_file` is present on edges.
- Ensure that `confidence` values map precisely to `EXTRACTED`, `INFERRED`, or `AMBIGUOUS`.

## Technical Approach
1. **Node Schema Alignment**:
   - Add `file_type: String` (restricted to the six valid types, defaulting to `"code"` for AST extraction).
   - Keep `kind` as metadata or Map it into `file_type`.
2. **Edge Schema Alignment**:
   - Rename/serialize `kind` field to `relation`.
   - Add `source_file` to `Edge`.
3. **Rust Types Update**:
   - Update `graphify-core/src/types.rs`.
   - Update all extractors to populate these fields correctly.
